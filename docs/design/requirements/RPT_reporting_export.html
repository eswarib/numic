NUMIC requirements / Cross-cutting

Reporting & export

Reporting turns a stored result into a record a clinician can file or share: who the baby is, what was measured, how old they were, how each measurement compared with its reference line, the points from each layer, the band, the rule revision and any recorded decision. It also produces a unit handover summary. Export to hospital electronic records comes later through EXT.

Scope

In scope

  • Per-assessment printable report
  • Unit handover summary
  • Report audit entries

Out of scope

  • Analytics extracts (LRN)
  • Audit trail export (LOG)
  • FHIR or EHR integration (EXT)

Users, data and interfaces

Users and callers

  • Clinicians filing a result in the notes
  • Ward teams at handover
  • Governance and audit reviewers

Data it owns

  • Generated reports are not stored; they are rebuilt from stored results so they always match the audit trail.

Interfaces

  • GET /api/v1/reports/assessments/{id} (printable HTML and PDF)
  • GET /api/v1/reports/units/{id}/handover

Functional requirements

RPT-F01MustProduce a per-assessment report with patient details, scan date and time, measurements, age at scan, reference values used, layer and metric points, band, rule revision, recorded decision and the disclaimer.The report for a stored result shows every listed item and matches the values in the clinician app.
RPT-F02MustShow on every report who generated it and when.The footer shows the user and the generation time in the unit's time zone.
RPT-F03MustWrite every report generation to the audit trail.Generating a report creates an audit entry with actor, patient record ID and assessment ID.
RPT-F04MustProduce a printable format from the clinical app.The report prints cleanly on A4 portrait with no cut-off columns.
RPT-F05ShouldProduce a PDF version of the per-assessment report.The PDF contains the same content as the HTML report.
RPT-F06ShouldProduce a unit handover summary listing active babies with latest band, last scan, overdue flag and pending decision.The summary for a unit matches the DSH list at the time it was generated.
RPT-F07MustUse the unit's configured band wording and disclaimer.Changing band wording in ADM changes newly generated reports.
RPT-F08LaterExport a result to the hospital record as structured data.Delivered through EXT, e.g. as a FHIR DiagnosticReport with Observations.
